# Web Frontend (React + Vite)

A minimal React login + upload UI that talks to the Node auth service and the FastAPI ML service.

## Env vars (optional)
Create `.env` and set:
```
VITE_AUTH_BASE=http://localhost:4000
VITE_ML_BASE=http://127.0.0.1:8081
```

## Run
```
npm install
npm run dev
```
Open the URL shown in the terminal.
